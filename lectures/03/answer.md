# 第3回 解答

## 演習

- **第1回（素のLLM）とエージェントの回答の違い：**

  第3回のエージェントは、用語集を検索するツールを利用し、講座の内容に基づいた回答を生成できた。実際に「3レベル」について質問すると、「基礎・実装・発展」の3段階を正しく説明し、関連する回も示した。一方、素のLLMでは外部の用語集を直接参照しないため、講座固有の情報について正確な回答が得られない可能性がある。

- **`--trace` で見えたツール呼び出し（ツール名と引数）：**

  ツール名：`make_quiz`

  引数：`{"lecture": 2}`

  第2回の確認問題を求めたところ、`make_quiz` が呼び出され、「LoRA」の意味を問う問題とその解答が生成された。

- **1つの質問でのLLM呼び出し回数（`requests`）：**

  `requests = 2`

  最初のLLM呼び出しでツールの使用を判断し、ツールの実行結果を受け取った後、もう一度LLMを呼び出して最終的な回答を生成した。

- **追加したツールと、docstringに書いた説明：**

  `make_quiz(lecture: int)` を追加した。

  指定した講義回の用語集からランダムに1つの用語を選び、その意味を問う確認問題と解答をJSON形式で返すツールである。

  docstringには、指定した回の用語から確認問題を作成すること、復習用の問題を求められたときに使用すること、引数 `lecture` に講義回数を整数で指定することを記述した。

## 宿題

- **取り組んだレベル：** 基礎

- **やったこと：**
  `app/agent.py` の `INSTRUCTIONS` に「確認問題を求められたら、必ず make_quiz ツールを使い、問題と答えを提示する。」という指示を追加した。変更前後で「第2回の確認問題を1問出して」という同じ質問を `--trace` 付きで実行し、ツールの呼び出しと回答内容を比較した。

- **結果：**
  変更前は「ファインチューニング」の意味を問う問題だけが表示された。一方、変更後は「Hugging Face Hub」の問題に加えて、その答えも表示された。どちらも `make_quiz` が `lecture=2` で1回呼び出され、LLMの呼び出し回数は2回だった。使用するツールや引数に変化はなかったが、最終回答の内容に違いが見られた。

- **気づき・疑問：**
  INSTRUCTIONSの書き方によって、同じツールを使っていても最終的な回答形式が変化することが分かった。また、ツールの呼び出し方は変わらなかったことから、今回の変更は主に回答の生成方法に影響したと考えられる。ただし、LLMの出力には揺らぎがあるため、指示の効果をより正確に調べるには複数回の実行が必要だと感じた。
